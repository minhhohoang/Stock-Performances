# Stock Performance Analysis

A CSC 369 class project exploring S&P 500 stock performance with **Python and PySpark**. The analysis compares dollar gains and percentage returns during the first half of 2025, then tracks selected stocks through Q3.

**Minh Ho-Hoang**

## Key Features

- **Data engineering:** Load stock data from Kaggle and reshape it for analysis using Spark DataFrames.
- **Time-series analysis:** Apply Spark SQL window functions to rank stocks and examine price changes.
- **Data visualization:** Use pandas and Matplotlib to compare stock performance over time.

## Highlights

The saved first-half rankings show **BKNG** leading in dollar gains (+$798.57 per share) and **HOOD** leading in relative returns (approximately +143%). The Q3 comparison explores how these two ranking methods relate to later performance.
